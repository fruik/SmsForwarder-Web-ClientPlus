# -Web-
本项目的前端 UI 界面与交互体验基于开源项目 CTCD/SmsForwarder-Web-Client，由作者在 Gemini协助下进行重新设计、美化与功能增强。
本客户端采用纯前端单文件（HTML + CSS + JavaScript）实现，无需复杂的后端编译与部署：克隆或下载本仓库的 index.html 文件。直接在任意现代浏览器中双击打开，或将文件托管至任意静态网页服务器。输入你的“短信转发器”后台服务地址与签名密钥（Key），即可开始远程管理。
